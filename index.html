Win-to-Race

Native macOS orchestration for multiple coding CLIs. One repository and one problem go in; isolated agent runs, logs, ADRs, feedback, and comparable results come out.

Read README Advanced task format

What V1 Does

Autonomous runs

W2R discovers available coding CLIs and starts isolated branches, workspaces, logs, and sessions.

Human in the loop

Agent questions remain visible so the developer can answer without manually driving each CLI.

Learning data

Feedback and runtime files create a long-term record of which agents work best for real tasks.

Project Status

  • Build-ready SwiftPM macOS app target.
  • Simple Mode for one-off repository tasks.
  • Advanced Mode for Markdown task queues.
  • Setup view with CLI checks, Keychain-backed API keys, and ENV editor.
  • Diagnostics view with copyable failure records.

Run Locally

Use ./script/build_and_run.sh from the repository root.

Win-to-Race is built for developers who want AI agents to race on real engineering problems without manual CLI orchestration.
